# Estudo — Engenharia de Software

Site interativo de estudo de Engenharia de Software (Prof. Jacques Oliveira), baseado nos 5 materiais da disciplina: Fundamentos, Fluxos de Trabalho de Ciclo de Vida, Modelos Ágeis, Arquiteturas de Software e TDD & Testes.

**Acesse:** https://luan-k10.github.io/estudo-engenharia-software/

## Conteúdo

- **Resumos** de 6 tópicos: princípios de Hooker, modelos de ciclo de vida, requisitos/UML (RF × RNF), Scrum/XP/Kanban, MVC/MVVM/Hexagonal/Clean e testes/TDD.
- **Comparativos**: tabelas lado a lado (modelos, arquiteturas, Scrum × XP × Kanban, papéis).
- **Quiz, simulado e flashcards** com explicação.
- **Discursivas** com resposta-modelo e um exemplo completo do trabalho (sistema de Biblioteca).
- **Treino rápido**: classificar frases (RF/RNF, papéis do Scrum, tipos de teste, arquiteturas, modelos).

Parte da central de estudos: https://luan-k10.github.io/estudos/engenharia/

HTML, CSS e JavaScript puros. O progresso fica salvo no navegador.
